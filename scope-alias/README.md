# @madeby/cli

**Reserved namespace.** The MadeBy provenance CLI is published as **[`madeby`](https://www.npmjs.com/package/madeby)** — install that:

```sh
npm install -g madeby
# or, no install:
npx madeby check
```

This `@madeby/cli` package exists only to hold the `@madeby` scope for the MadeBy
project. It ships no code. Source: https://github.com/MacDougherty/MadeBy
